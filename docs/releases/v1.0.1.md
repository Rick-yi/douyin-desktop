# 闪拓 v1.0.1

Windows 桌面版抖音多账号管理工具 + 卡密授权。

## 主要功能

- **多账号管理**：扫码登录、账号隔离、按账号代理、在线状态
- **聚合聊天**：文本、图片、文件、富消息（链接卡/作品卡/名片/文件卡）、引用回复、转发、撤回、草稿
- **自动回复**：按账号/会话类型/关键词/正则匹配，规则冷却、转人工暂停、文本/表情/卡片回复
- **智能群发**：多文案轮换、失败重试、排除最近联系过的人、定时发送
- **线索雷达**：关键词搜视频、评论采集、持续监控、线索审核、CSV 导出
- **敏感词与合规**：本地词库 + 正则 + 合规改写建议
- **发送保护**：每日/每小时配额、随机间隔、连续失败熔断、风控信号熔断
- **本地数据**：SQLite 存储，数据留在本机；支持备份/恢复
- **卡密授权**：设备绑定、心跳续签、断网宽限、强制更新
- **按账号代理**：HTTP/HTTPS 代理，绑定后 fail-closed，不回退真实 IP

## 安装

1. 下载 `shantuo-1.0.1-x64.exe`
2. 运行安装包，按提示完成安装
3. 打开客户端 → 左侧「授权」→ 输入卡密 → 激活
4. 「账号管理」→ 添加账号 → 抖音 App 扫码

> 本安装包**未做代码签名**。Windows SmartScreen 可能提示“未知发布者”，
> 选择「更多信息」→「仍要运行」即可。正式分发建议使用你自己的代码签名证书。

## 系统要求

- Windows 10 / 11 x64
- 4GB 以上内存
- 500MB 以上磁盘空间
- 能访问抖音和授权服务

## 重要说明

- 本构建需要卡密激活；没有卡密时无法使用发送、群发、线索雷达、监控、自动回复等功能。
- 授权服务地址由客户端内置，可用环境变量 `LICENSE_SERVER` 覆盖。
- 本地数据默认在 `%APPDATA%/Shantuo`，不会上传到授权服务端。
- 安装包和源码**不包含**任何真实账号 Cookie、Session、设备指纹或卡密。
- 仅用于自有账号管理和学习研究，请遵守抖音平台规则，不要用于垃圾信息、骚扰、欺诈或群控。

## 已知限制

- 协议 SDK 依赖 `douyin-im` 内部接口，平台升级可能导致失效。
- 二级评论未打通，只采一级评论。
- 持续监控只在客户端运行时生效。
- 代理只支持 HTTP/HTTPS；修改绑定后需要重连账号。
- 本地 SQLite 和 session 当前为明文，建议开启 BitLocker。
